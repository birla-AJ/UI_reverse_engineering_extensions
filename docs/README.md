# UI Reverse Engineer Pro

AI-powered Chrome extension for analyzing, reconstructing and exporting websites.

## Features

### Analysis

- DOM analysis
- Navbar detection
- Hero detection
- Footer detection
- Hover detection

### Capture

- DOM capture
- CSS capture
- Interaction capture

### Assets

- Image collection
- SVG collection
- Video collection
- Font collection
- Asset download

### Reconstruction

- Component extraction
- Blueprint generation
- Responsive generation

### Design System

- Colors
- Typography
- Radius
- Shadows

### AI

- AI HTML generation
- AI CSS generation
- AI reconstruction

### Export

- HTML export
- Asset export
- ZIP export
- Manifest export

## Usage

1. Open any website

2. Click Analyze

3. Click Export

4. Download website-export.zip
